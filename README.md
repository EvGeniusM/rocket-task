# Mobile Library API

REST API для персональной библиотеки книг. Пользователи регистрируются, хранят
книги в личной библиотеке, выдают другим пользователям доступ на чтение своей
библиотеки, мягко удаляют и восстанавливают книги, а также ищут книги во внешних
каталогах (Google Books, МИФ) с возможностью сохранить найденную книгу к себе.

Реализовано без фреймворка: компактный слой MVC + сервисы поверх `bramus/router`
и PDO. Аутентификация на токенах (непрозрачные bearer-токены). Вся бизнес-логика
лежит в сервисах, контроллеры остаются тонкими.

## Что умеет

Все ответы в формате JSON. Эндпоинты с пометкой «авторизация» требуют заголовок
`Authorization: Bearer <token>`.

| Метод | Путь | Авторизация | Описание |
|-------|------|-------------|----------|
| POST | `/register` | нет | Регистрация; возвращает bearer-токен |
| POST | `/login` | нет | Вход; возвращает bearer-токен |
| GET | `/users` | да | Список пользователей (id и логин) |
| POST | `/users/grant-access` | да | Выдать другому пользователю доступ к своей библиотеке |
| GET | `/users/{id}/books` | да | Книги другого пользователя (нужен выданный доступ) |
| GET | `/books` | да | Список своих книг |
| POST | `/books` | да | Создать книгу: заголовок плюс текст или загруженный `.txt`-файл |
| GET | `/books/{id}` | да | Прочитать книгу |
| PUT | `/books/{id}` | да | Обновить заголовок или текст |
| DELETE | `/books/{id}` | да | Мягко удалить книгу |
| POST | `/books/{id}/restore` | да | Восстановить мягко удалённую книгу |
| GET | `/search?q=` | да | Поиск по внешним каталогам |
| POST | `/books/external` | да | Сохранить книгу из результатов поиска в свою библиотеку |
| GET | `/docs` | нет | Интерактивная документация API (Swagger UI) |

## Требования

- PHP 8.2+ (с расширениями `pdo_mysql` и `curl`)
- MySQL 8
- Composer

## Установка

```bash
composer install
cp .env.example .env          # при необходимости отредактируйте DB_*
```

Создайте базу и загрузите схему (имя базы по умолчанию — `rocket_task`):

```bash
mysql -u root rocket_task < database/schema.sql
```

## Запуск

```bash
php -S localhost:8000 -t public public/router.php
```

Аргумент `public/router.php` обязателен: без него встроенный сервер PHP считает
`/docs/openapi.json` отсутствующим статическим файлом и отдаёт 404, не доводя
запрос до приложения.

Откройте `http://localhost:8000/docs` — это интерактивная документация. У публичных
эндпоинтов нет иконки замка; для остальных нажмите «Authorize» и вставьте токен из
ответа `POST /register`.

## Тесты

Тесты используют отдельную базу (`rocket_task_test`) и поднимают собственный
PHP-сервер для функциональных тестов.

```bash
cp .env.testing.example .env.testing
mysql -u root -e "CREATE DATABASE rocket_task_test"
composer test
```

`composer test` запускает PHPUnit. Схема загружается в тестовую базу автоматически
из бутстрапа тестов; таблицы очищаются между тестами.
